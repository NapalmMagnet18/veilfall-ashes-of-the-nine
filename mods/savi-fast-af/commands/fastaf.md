# /fastaf

- **invocation:** `/fastaf` (also `/fastaf audit`)
- **what it means:** "adopt the SAVI FAST AF protocol in this room — 60 process rules that make you faster and lighter to build with."
- **what it shifts in Savi:** she loads the mod's `fast-af-protocol` skill, mirrors the rules she isn't already running into her own memory, and confirms in ONE line. From that message on, the rules are active reflexes.

---

## `/fastaf` — adopt

Run this sequence, tight and quiet:

1. **Load the skill:** `use_skill({ skills: ["savi-fast-af#fast-af-protocol"] })` — the 60 rules, grouped and numbered.
2. **Diff against yourself:** which of the 60 are you NOT already running? Be honest — the audit exists to catch drift.
3. **Mirror the gaps:** write the missing rules (condensed is fine — reflexes, not prose) into `memory/their-patterns.md` under a `## SPEED PROTOCOL` heading. If that file is near its cap, put them in `memory/savi-workflow.md` and leave a pointer — that's rule 42 in action.
4. **If this room is part of a Savi network** with a shared Commons and adoption trackers: tick yourself into the tracker per that network's own ritual. If not (most rooms): skip — the memory mirror IS the adoption. The mod works standalone; no shared infrastructure required.
5. **Confirm in one line.** Something like: "fast af — 60 active, N newly adopted." Nothing ceremonial. The whole point is fewer words.

**Do not** recite the rules back into chat unless asked. Adoption is a write, not a speech.

## `/fastaf audit` — self-grade

The creator wants to know if you're actually running the protocol, not just holding it.

1. Load the skill (if not already in context this session).
2. Review your own behavior THIS session against the 60 — your actual tool calls, not your intentions. Look especially for the classic violations: sequential calls that were independent, re-reads after a save receipt, narration between calls, 3-option menus, un-scoped greps, double-verified edits.
3. Report short: rules broken (by number + one-line evidence from this session), rules you're clean on as a count, and the ONE habit you'll fix first.
4. If the session is too young to have evidence, say so — "not enough tape yet, ask me after a build."

---

## What NOT to do

- Don't make adoption a ceremony. One confirming line, then back to whatever the creator actually asked.
- Don't override the creator's live word with a rule — chat always wins.
- Don't apply rules against the game's needs. These tune Savi's process; the game's quality bar doesn't move.
- Don't re-adopt on every invoke. If the rules are already mirrored, `/fastaf` is a no-op plus a one-line "already running all 60."
